学习通智能助手 v1.0

文件说明：
- index.html：主程序
- manifest.webmanifest：PWA 安装配置
- service-worker.js：离线缓存
- icon.svg：主屏幕图标

重要：
1. 本项目是独立的学习管理工具，不是超星/学习通官方产品。
2. 不会登录、控制或自动播放学习通 App，也不会伪造课程完成状态。
3. 课程、章节和计时记录保存在当前浏览器本地存储中，请定期导出备份。
4. 如需完整 PWA 安装与离线缓存，必须把文件部署到 HTTPS 网站；直接打开 HTML 文件不支持完整 PWA。
5. 计时器切换到后台后可能受到 iOS 节能与网页挂起机制影响，请返回页面确认计时。
